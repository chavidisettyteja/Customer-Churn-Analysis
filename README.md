# 📊 Customer Churn Analysis using Python & SQLite

## 📌 Project Overview

Customer churn is one of the biggest challenges faced by subscription-based businesses. This project focuses on analyzing customer churn data stored in a SQLite database to uncover patterns, identify factors contributing to customer attrition, and derive actionable business insights through Exploratory Data Analysis (EDA).

The analysis was performed using Python, SQL, and data visualization libraries to better understand customer behavior and support data-driven decision-making.

---

## 🎯 Objectives

- Connect and query data from a SQLite database
- Perform data cleaning and preprocessing
- Handle missing values and duplicate records
- Explore customer demographics and service usage
- Analyze customer churn trends
- Create meaningful visualizations
- Generate business insights from the data
